About this app

NOT BYPASS is a private Android browser built around Mozilla GeckoView. It opens pages, keeps tabs, bookmarks, and settings on the phone, and does not use a custom server, account, or analytics kit.

It was made so a browser does not have to ask who you are. Close the app and the choice stays on the device.

No account No analytics No ads No custom backend

What's new

1.1.0 Fuller browser shell, settings pages, downloads, notifications, and private session handling.
1.0.0 First signed release. GeckoView engine, tabs, bookmarks, local JSON storage.

Features

TabsMultiple tabs and a separate private session.
BookmarksSaved in app-private JSON on this phone.
DownloadsAndroid DownloadManager. Files go to the system download folder.
SearchDefault engines plus custom search engines.
Privacy controlsTracking protection, cookies, HTTPS-only, site permissions.
AppearanceTheme, toolbar position, text size, homepage.
Network toolsConnection status and diagnostics on the device.
Backup fileLocal export and import of settings. No cloud.

Settings

Twenty-four settings pages cover general, search, privacy, network, proxy limits, downloads, tabs, permissions, appearance, accessibility, advanced, storage, passwords, media, notifications, homepage, data, updates, performance, developer tools, backup, browser experience, network dashboard, and about.

Data safety

Data collectedNone by the app. No account, no analytics, no ads.
Data storedBookmarks, settings, and session choices stay in app-private files.
HistoryBrowsing history is not stored by the app.
BackupAndroid backup is disabled. You can export a local file yourself.
DeleteUninstall removes the app’s private files. Flash storage can still leave old blocks. This is not forensic erasure.

Permissions

  • Internet and network state, so pages can load
  • Notifications, for download and network alerts you turn on
  • Camera, microphone, and location only if a site asks and you allow it
