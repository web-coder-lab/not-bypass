NOT BYPASS

Private browser for Android

v1.0.0 · arm64 · no account

A browser that does not ask who you are.

Built so a phone can open pages without a custom server, without an account, and without an analytics kit. The engine is Mozilla GeckoView. Tabs, bookmarks, and settings stay in app-private files.

Download APK Source on GitHub

Why this app exists

Most browsers add an account, a sync server, or a product analytics path. NOT BYPASS was made to avoid that path. Open a page, keep the choice on the device, and close the app when you are done.

What is real

  • Real GeckoView sessions, not a fake WebView shell
  • Normal tabs and a separate private session
  • Bookmarks and settings saved on the device
  • Android DownloadManager and native notifications
  • No custom server, no analytics, no account

What this is not

  • Not a Tor browser and not safer than Tor
  • Not a promise that every website is anonymous
  • Not a claim that deleted files can never be recovered from flash storage
  • Not a hidden network. This page is a normal GitHub Pages site

Data on the phone

Bookmarks, settings, and session choices are stored in the app’s private files. Uninstalling the app removes those files from the app. Android backup is disabled. Flash storage can still leave old blocks that a lab might try to read. This app does not claim forensic erasure.

Engine GeckoView 140
Android 8.0 and newer
Storage Local JSON only
Backup Disabled

Install

  1. Download the APK on your phone.
  2. Allow install from this browser if Android asks.
  3. Open NOT BYPASS. Grant notification and download access only when a feature needs them.
